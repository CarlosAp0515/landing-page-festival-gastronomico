Fusion Gourmet Festival Landing Page
 Description

This project is a responsive landing page created for the Fusion Gourmet Festival, an event that celebrates high-end cuisine, culinary innovation, and unique gastronomic experiences.

The goal of this website is to present the festival in an elegant and modern way, encouraging users to explore the event and reserve tickets.

Technologies Used
HTML5 (Semantic structure)
CSS3 (Flexbox, Grid, Responsive Design)
 Project Structure
Header: Navigation bar and festival logo
Hero Section: Main call-to-action with a reservation button
Events Section: Schedule of tastings using an HTML table
About Section: Information about the festival and its philosophy
Multimedia Section: Food gallery and embedded video
Chefs Section: Featured guest chefs
Footer: Contact information and social media links
Responsive Design

The website is fully responsive and adapts to:

Desktop (>1024px)
Tablet (≤1024px)
Mobile (≤768px)

Media queries were used to ensure a proper layout across all devices.

 How to Run the Project
Download or clone the repository
Open the project folder
Open the index.html file in your browser
 Extra Features
Styled HTML table with <thead>, <tbody>, and <tfoot>
CSS hover effects and subtle animations
Grid-based image gallery
Embedded YouTube video
